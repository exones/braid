R did not query GitHub independently. This agrees with [npm's bin documentation](https://docs.npmjs.com/cli/v11/configuring-npm/package-json/#bin), which distinguishes Unix symlinks and Windows command wrappers.
- Expected behavior / action: retain Windows wrapper validation; on POSIX resolve and verify the bin symlink target against the installed entry and then run every installed-executable scenario. Preserve the source-independence checks. Require successful hosted Ubuntu verification and artifact upload on the corrected head; do not skip or weaken the installed proof.
