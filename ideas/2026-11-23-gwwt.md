Projects with their own work tracker (initiatives)

Field report, Everix monorepo (2026-11-23). The repo already tracks work in `initiatives/<project>/NNN-slug/` (initiative.md with front matter, prompts/, reports/, checkpoints/, phases) with its own board reading only that folder, and AGENTS.md requires owner reports in the initiative's reports/, which conflicts with braid's report.md in braids/. The concepts map almost 1:1 (initiative → braid, phase → strand, prompts → brief, reports → report.md, checkpoints → logs), but braid's root is fixed to braids/ and there is no importer like import-backlog. Wanted, one of: an initiative link field on a braid with the report copied or linked; an importer/exporter; a configurable braid root and layout.

Related: braid import-backlog, docs/braids-format.md, D33.
