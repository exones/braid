HTML reports before questions and at the end of work

When braid stops to ask the user something, and when it finishes a piece of work, it shows a formatted HTML report (rendered in the host, e.g. T3's HTML preview) instead of only Markdown in chat. The report lays out the context, what was done and what is being asked, so the user can read it at a glance before answering. This adds a presentation format for the coordinator's rundowns and final reports; it doesn't change what they contain.
