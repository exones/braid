Use AGENTS.md and CLAUDE.md to make the braid skills work better

In a project that uses braid, its AGENTS.md and CLAUDE.md could carry a short, ready-made section that helps agents reach for the braid skills at the right moment and use them well: which skill fits which request, where BRAID.md and braids/ are, and what agents must never do around braid state. The installer or docs/getting-started.md could offer that section, so a new project gets it without writing it by hand. Today getting-started does not mention AGENTS.md or CLAUDE.md at all.

Related: idea 2026-11-19-co8u "BRAID.md, AGENTS.md and learnings: one clear place for each"; docs/getting-started.md; this repo's AGENTS.md ("Where to look" section) as a possible model
