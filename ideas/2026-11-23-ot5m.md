braid init and braid skills install

A new repository becomes a braid project with one command: `braid init` writes BRAID.md (gate, main, ci, run, models) from what it finds (package.json scripts, the default branch, CI workflows), adds the braids/ folder and the agent-instruction pointers, and says what is left to fill in. `braid skills install` installs the braid skills for the providers present (Claude, Codex, Cursor), so a user doesn't need this repo's scripts/Install-Skills.ps1.

Why: today a new project is set up by hand following docs/getting-started.md, and the skills come from a PowerShell script in braid's own repo.

Related: docs/getting-started.md, scripts/Install-Skills.ps1, P7 · 0067 (board service install).
