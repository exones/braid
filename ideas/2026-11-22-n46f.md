Pushes only for what needs the user, when a PM runs the braids

When a PM runs the braids, the user gets a phone push only for what really needs them. Routine traffic stays silent: strand merges, checks passing, coordinator requests the PM answers itself. Today both T3's thread notifications and the board's ntfy pushes (D70) fire for every coordinator request, because each one opens a board request and lands in Needs You, even though the PM handles nearly all of them. This adds a "who is it for" to requests, and lets the PM decide what reaches the user's phone.

Why: under a PM the user relies on notifications that are "plenty and not necessarily require me"; they want to limit them to the PM's own notifications.

How it could look, roughly:
- A request knows its addressee. `braid ask` gets `--for pm|user`; a coordinator "Launched by a PM" asks `--for pm`. The board shows those in a new lane, "With the PM" (or dimmed in Needs You), and never pushes them.
- When the PM escalates to the user (an expensive-to-reverse decision, a security merge, a weekly limit), it re-addresses the request: `braid ask --for user`, or a new `braid escalate <id>`. Only then does the item enter Needs You and push, with the PM's question as the body and the PM thread as the click link.
- The PM can also push directly for things with no board item: a digest, "nothing can run until you act", a provider pause with the user's choice. Either `braid notify send --title --message --priority`, through the same ntfy topic and privacy rules, or the T3 push tool.
- Per-machine setting in ~/.braid/notify.json: `mode: all | escalations` (default `all` without a PM). With `escalations`, the board pushes only Needs You items addressed to the user, plus braid Done (or not, by a flag).
- The user can then mute T3's per-thread notifications for coordinator, worker and checker threads and keep only the PM's.

Related: D70 (phone pushes over ntfy), D78 (one board for all projects), docs/board.md "Notifications", the braid-pm skill ("Answering coordinators", "The digest"), the braid skill "Launched by a PM".
