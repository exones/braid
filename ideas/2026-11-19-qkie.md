Each braid keeps the project's docs current

Every braid checks whether its change makes the project's docs out of date (README, docs/, usage and help text) and, if so, updates them in the same PR, so docs never lag behind what was built. Today the worker skill only says "Decided means documented" (update the doc for what the user decided, plus the decisions record), and the reviewer only reads docs made stale around the diff; this makes "are the docs still true?" an explicit step for every item, not just for decisions.
