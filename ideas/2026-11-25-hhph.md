A `pm/` branch without a plan file shows on the board as a broken programme ("plan unreadable: no pm/<slug>.md on pm/<slug>").

2026-11-25, dctl-studio: the PM put an AGENTS.md change on `pm/user-busy-rule`. The board listed it as a programme with a red error, and the user took it for a programme they hadn't ordered.

Proposal: a `pm/<slug>` branch counts as a programme only when it holds `pm/<slug>.md`. Others are ignored, or listed once under Not ready ("pm/user-busy-rule: no plan file, not a programme"). The braid-pm skill already implies that only the plan branch uses `pm/`; one line in the plan template would make it explicit.
