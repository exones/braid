Learnings: workers leave findings for future workers

While a braid or strand is worked, the agents learn things about the project: what to avoid, how something is done here, what broke before. Today that knowledge stays in their thread, report or PR and is lost to the next worker. The idea: important findings go into a file that future workers on the same project read and follow, so each item starts with what earlier ones learned.

Why: so future workers on the same project avoid known pitfalls and do things the way the project does them, instead of learning it again.

Related: idea 2026-11-18-ndmt Review checklist that grows from past mistakes (the same idea for reviewers), idea 2026-11-18-bvcs Workers say how they verified the work, BRAID.md, AGENTS.md
