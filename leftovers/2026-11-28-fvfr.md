The Windows test "clean says a worktree is still in use" can fail under load

test/start-clean.test.ts: its helper process holds the worktree folder for only 20 s; on a loaded machine the test can reach its check after the hold ended, so braid clean removes the folder and the test fails. Seen once in 0078/M's first gate (PR #381), passed alone and in the next gate. Hold the folder until the test signals it is done (a file or stdin), not for a fixed time.
