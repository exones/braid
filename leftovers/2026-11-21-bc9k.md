Cut git process starts in the node tests

Spike 0057/A counted about 9,500 process starts in test/*.test.ts, 96% of them git (fixture repositories built per test, repeated rev-parse calls in the commands).
Starting processes is most of the remaining node --test time on Windows (CPU-bound, 25-140 ms per start) and costs Linux too.
Where: the fixture helpers in test/*.test.ts (build each file's repositories once and copy them) and rev-parse calls under src/. Needs its own measurement first.
