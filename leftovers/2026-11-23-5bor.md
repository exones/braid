The board writes the request record with synchronous Git

Recording met from the board (src/board/wake.ts through src/braids/requests.ts) runs Git commands synchronously inside the board process, so a slow push blocks a refresh and the page. Moving the write off the refresh path (async Git, as the reads do) would keep the board responsive.
