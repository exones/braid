Board has no dark theme

The board (web/src, its CSS) has only a light theme, so the README screenshots in docs/images/ (board.png, item-page.png, board-phone.png, inbox.png) show light on a GitHub page viewed in dark mode, and the board itself ignores the OS dark setting. A dark theme following prefers-color-scheme would fix both; the README images would then get dark variants with <picture>.
