A wait replaces the same asker's open question on one item

In 0070, a new request from the same asker on the same item withdraws the open one ("replaced by q-…"). The PM's live check of #273 found that this also covers waits: a coordinator's cross-braid wait (--to <braid> --done-when braid:<n>) withdrew its open question to the user on the same item (q-08xm replaced by q-gjlj). So a coordinator can't hold a question and a wait at once. P6 builds waits on this record, so decide there whether replacement should apply only within the same kind (question replaces question, wait replaces wait).
