Volta braid.cmd fails when LOCALAPPDATA is redirected; same-named repos share a worktrees folder

Found in braid 0045's two-checkout trial. (1) The installed braid.cmd (Volta shim) stops with "Could not determine LocalAppData directory" when LOCALAPPDATA points elsewhere, so tests and scratch runs that redirect home folders must call node dist/cli.js. (2) Two repositories with the same folder name share ~/braid-worktrees/<repo>/ (src/braids/worktrees.ts), so their item worktrees can collide; this matters once braid serves several projects (0045's follow-up "Project list").
