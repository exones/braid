Local board opened as localhost hides Open thread

web/src/api.ts decides remoteBoard as location.hostname !== "127.0.0.1", so a local board opened as http://localhost:<port> is treated as remote and hides the open button (the local Host check already refuses that Host for actions, so it is not a hole, only a confusing page). Decide remote from what the server says (for example a field in the board data) instead of the page hostname.
