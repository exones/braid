Recorded PM checker threads are never dropped

0071/C made the PM record its delegated live checker with braid review pm/<slug> --thread <id> (2h98), because T3 lists no subagent threads. Those records in .braid/reviews.json are never removed for a pm/ item (braid clean removes reviewers only after an item PR merges), so every finished checker costs one t3 thread show per board refresh (src/board/t3.ts readFresh) for ever. Drop a pm/ record once its thread is no longer running, or on the next record for the same programme.
