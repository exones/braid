No way to tell whether T3 knows a project folder

The t3 CLI has no project list (t3 project has only add/remove/rename), `t3 thread list --project <folder>` prints [] for a known project with no threads and for a folder T3 doesn't know, and thread JSON carries only projectId, never the folder. So 0049/A dropped the "T3 doesn't know this project" readiness check, and 0049/B's planned `braid projects suggest` (T3 projects with a BRAID.md) has no source. A `t3 project list --json` with each project's workspace root, on T3's side, would allow both.
