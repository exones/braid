braid limits can't read T3's usage cache after a usage reset

After the user applied a weekly usage reset (2026-11-24), `braid limits` says "verdict: unknown (launch as usual): usageLimits.windows is not a list of windows". In ~/.t3/caches/Claude_Everix.json, `usageLimits` now has `checkedAt`, `windows` and a new `resetCredits`, and `windows` is an object keyed "0", "1", "2" instead of an array. While it reads unknown, the board's limits pause is blind for Claude_Everix: the next threshold won't pause anything. Fix: accept an array-like object (and ignore unknown keys such as resetCredits), with a test from this shape; check how T3 writes it (a version change or a serialization quirk after a reset).
