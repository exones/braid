A request-record write costs about 38 git processes on Windows

Measured in 0078/J (PR #332): one write to braid-requests (src/braids/gitbranch.ts writeBranchUnlocked, under lockedBranch) spawns about 38 git processes and takes 7-9 s under load, which is why queued writers waited past 60 s. Fewer git calls per write (plumbing in one process, cached refs) would shorten the lock hold and the queue. Fits P24 (one git runner).
