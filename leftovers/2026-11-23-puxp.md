braid clean treats a braid branch as merged after an early PR into main

In 0073 an intermediate PR (#279) from the braid branch braid/0073-… into main merged 0073/A early while the braid went on. braid clean --yes then listed the braid branch and its worktree for removal ("PR #279 merged") and only skipped them because the branch was checked out in the coordinator's checkout. Run from another checkout it would remove the live braid branch's worktree and local branch. braid clean (src/commands/clean.ts) should not count a braid branch as merged while the braid is not Done, or should judge it by the braid's final PR.
