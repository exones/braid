git cat-file --batch has no timeout on the board

catBatch in src/braids/gitio.ts starts git cat-file --batch with no timeout, while gitAsync has 60 s.
A hung git process would leave the board read, and so the first /api/board request, waiting forever.
Give it the same timeout and kill the process on expiry.
