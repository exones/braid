Request codes are looked up case-sensitively

What: request codes are made and stored lowercase (q-l9en), but lookup by code is case-sensitive. braid requests Q-L9EN is refused as "not a request code", and braid answer Q-L9EN / braid withdraw Q-L9EN are refused with the misleading "not a braid or strand id". Nothing is written under a wrong code.
Where: src/commands/requests.ts (code lookup in answer, withdraw, requests), src/braids/requests.ts.
Why: the user refers to questions by code from any thread and may type it capitalised (some displays capitalise the first letter of output, seen in 0070/E). Lower-case a /^q-/i code before lookup and name it as a request code in the refusal; add a test.
