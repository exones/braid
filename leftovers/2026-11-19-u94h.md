catBatchSync has no failure test

catBatchSync (src/braids/gitio.ts, added by 0029) has no test for a Git failure, a missing object or a hung process, and unlike the async catBatch it takes no command override to inject a hang.
On a non-zero exit it returns nulls, prefetchBriefs does not cache them, and gitTree.read falls back to `git cat-file blob` with no timeout.
A test for each case would lock the fallback behavior of braid list --open, braid view --links and braid check.
