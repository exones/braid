The board could steer busy agents and drop polling through T3 MCP

T3 exposes its MCP server to outside agents at <environment-address>/mcp over HTTP with OAuth (docs/user/outside-agents.md in pingdotgg/t3code; a one-time sign-in grants a level up to Full access). As an MCP client the board could call t3_thread_send with mode auto, which steers a running turn; t3 thread send (T3 v0.1.11) only queues for a busy thread, so after 0074/C a worker in a long turn sees the pause only when the turn ends (D108). MCP Events (io.modelcontextprotocol/events: turn ended, agent waits on a person; poll, stream or webhook) could replace part of the board refresh polling (P24, the board stays fast under load). Needs a stored OAuth token: a security decision of the user, asked by the PM on 2026-11-25.
