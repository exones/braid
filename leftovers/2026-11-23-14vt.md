The board service log could be owner-only like the address file

What: ~/.braid/board-<port>.log, written by braid board --service, inherits its folder's ACL on Windows (on this PC CodexSandboxUsers can read ~/.braid); it holds no token, but it holds the board's paths and errors.
Why: the same owner-only rule as the address file (D92) would keep the folder's other readers out.
Where: src/commands/board.ts (the --service log), the ACL helper of 0067/C in src/board/address.ts.
