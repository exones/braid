A request handle's 4-character suffix can be all digits (q-0731), and then braid withdraw/answer/eta <suffix> reads it as a braid number: 'no braid 0731'. test/request-words.test.ts ('every command takes the name loosely…', last line) withdraws by a random suffix, so it fails about once in (36/10)^4 ≈ 170 runs; it failed on PR #324's Windows CI at d8e4d784 (run 45801768762). Either never generate an all-digit suffix, or try the request suffix when no braid has that number; fix the test to not depend on the random draw.
