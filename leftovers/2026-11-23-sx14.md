braid forward doesn't take a request code

After 0070, `braid answer`, `withdraw` and `requests` take a q-code, but `braid forward q-ocph` fails ("not a braid or strand id: q-ocph"); the PM had to use the strand id (0071/B). Accept a code everywhere an item id is accepted for a request.
