T3 MCP client: test the refused redirect and the bare 5xx, and read the token once

src/t3mcp/client.ts (0080/B) refuses HTTP redirects and maps a bare 5xx with no JSON-RPC body to unreachable, but test/t3mcp.test.ts has no test for either (a 302 from the mock, a 503 with an empty body). toolFailure also calls token() a second time instead of reusing the value it already read. The redirect refusal is what keeps the token from following a redirect, so it deserves a test; 0080/D, which feeds real tokens into this client, is the natural place.
