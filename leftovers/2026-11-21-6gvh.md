Project names that differ only by case share a worktrees folder on Windows

What: since 0053/B each listed project has its worktrees in ~/braid-worktrees/<project name>/, but projects.json treats `App` and `app` as two names, so on Windows (case-insensitive folders) both go to one folder and their items can collide.
Where: src/commands/projects.ts (braid projects add, name validation) and src/braids/worktree-folders.ts.
Why: the collision 0053/B removed for same-named checkouts comes back for names that differ only by case; refusing such a name in `braid projects add` (compared like folderKey) would close it. Tier S.
