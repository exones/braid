A gone need is not cleared on the phone when its item has another push in the same snapshot

What: src/notify/notifier.ts (lines 140-141) clears a need that went away only when the same item has no other push in that snapshot; a Done push carries sequence: null, so it does not replace the need either. An answered request with no other push is cleared (tested).
Why: a stale Needs You push can stay on the phone after the request was answered.
Where: src/notify/notifier.ts.
