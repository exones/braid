Docs gate fails locally in a worktree with a long path on Windows

The 0048/C worker found that `npm run verify`'s docs gate fails in a braid worktree with a long path on Windows: it passes the Markdown paths on one command line, about 32.6k characters, over the Windows limit. The worker ran the gate from a short `subst` drive instead; CI is unaffected. Fix: pass the file list in chunks or through a file or stdin instead of the command line.
