Two boards on one project both send a wake

The wake (src/board/wake.ts, steerer tick step 4) sends first, then records met on braid-requests. Two boards serving the same project (say a service and a manual run) each see the open request and each send the wake before either records met. One board per project is assumed but not enforced; a lock or a check of the record right before sending would close it.
