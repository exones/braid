Flaky hung cat-file test in board-cheaper-reads

The test "a hung git cat-file --batch ..." in test/board-cheaper-reads.test.ts uses a 400 ms timeout
that races the start-up of the child node process when the full suite runs on Windows, so the gate
fails at random (seen locally in 0039; it passes 3 of 3 runs on its own). A longer timeout or a
start-up handshake before the clock starts would make it stable.
