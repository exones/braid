Unit test for the Tailscale Host allowlist

The HTTP tests of the Tailscale listener (test/board-tailnet.test.ts, around line 204) bind it to 127.0.0.1, so Host 127.0.0.1:<port> is allowed there and a bind to 0.0.0.0 would still be reachable in those tests. Nothing locks the production allowlist built by tailnetHosts() in src/board/tailnet.ts to the Tailscale IP and the MagicDNS name only. Add a unit test of tailnetHosts("100.64.0.7", name, port) so a regression that widens the Host check fails.
