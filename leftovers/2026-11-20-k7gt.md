Push a braid's own request even when a strand need outranks it

The board notifier (src/notify/message.ts, pushesOf) sends one push per need it reads from a card: the
card's top need and its strand needs. When a more urgent strand need sits above the braid's own request
on the card, that request is pushed only once it becomes the top need, so the user can miss a
coordinator question while a strand is in Needs You.
