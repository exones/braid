Open thread still reloads the braids

openAction (src/commands/board.ts) calls src.braids() (loadLiveBraidsAsync) before taking the link from the snapshot, so Open thread still runs the git reads of the braids.
It could find the braid in the snapshot instead; this costs time on large repositories.
