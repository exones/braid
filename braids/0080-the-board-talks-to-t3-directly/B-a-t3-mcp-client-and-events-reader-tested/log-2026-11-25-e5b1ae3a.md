Built the client, reader, mock and tests (the commit "feat: a T3 MCP client and events reader").
Decided (architecture, cheap to reverse): a failed tool (`isError`) is an `error` whose `code` is T3's failure code, so 0080/D can show `runtime_mode_escalation_denied`.
Decided: a 5xx with no JSON-RPC body counts as `unreachable` (retry later); a 403 or other bare status is `error`.
Decided (security): redirects are refused; no fetch error message or cause is passed on, because fetch quotes a header value it rejects, token included; server text is stripped of the token.
Decided: an answer sent as server-sent events is read too, since the call's Accept header offers it.
