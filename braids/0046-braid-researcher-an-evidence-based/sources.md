- S1 How we built our multi-agent research system (Anthropic Engineering) — https://www.anthropic.com/engineering/multi-agent-research-system · version: published 2025-06-13 · read: whole · says: give each subagent "an objective, an output format, guidance on the tools and sources to use, and clear task boundaries"; scale effort to the query (simple fact-finding: 1 agent, 3–10 tool calls); early agents preferred "SEO-optimized content farms" over authoritative sources until prompts gained source-quality heuristics; start broad, then narrow; agents kept searching after they had enough until given stop guardrails; prefer heuristics to rigid rules. · adopted: the first-message contents (question, decision, time box), the evidence ranking against secondary content, and explicit stop rules (practices 2 and 9). Not adopted: parallel subagent fan-out and a separate citation agent; the researcher launches no agents and cites inline.
- S2 Preregistration (Center for Open Science) — https://www.cos.io/initiatives/prereg · version: none shown (mentions events up to 2023) · read: whole · says: "the same data cannot be used to generate and test a hypothesis"; specify the plan in advance; changes after results are known are labelled exploratory; deviations are reported transparently. · adopted: "frame first" and keeping the frame, with later sub-questions marked as added (practice 1). Not adopted: a registry or formal plan document; the frame lives in the researcher's working notes and report.
- S3 SIFT (The Four Moves), Mike Caulfield — https://hapgood.us/2019/06/19/sift-the-four-moves/ · version: posted 2019-06-19 · read: whole post body (comments not read) · says: investigate the source before reading it; "find better coverage" rather than trusting the source that reached you; "trace claims, quotes, and media back to the original context". · adopted: trace a quoted claim to where it first appeared (practice 2) and count copies of one source once (practice 5).
- S4 Hierarchy of evidence (Wikipedia) — https://en.wikipedia.org/wiki/Hierarchy_of_evidence · version: last edit 2026-10-22 per the subagent's summary of the footer (not seen verbatim) · read: part (body through reference 8, about 54%) · says: ranks kinds of method "according to the potential for that method to suffer from systematic bias"; expert opinion and "first principles" reasoning sit at the bottom; critics say the ranking is "not absolute". · adopted: an ordered evidence ranking with unsupported opinion (here model memory) at the bottom (practice 2). Not adopted: the medical levels themselves; braid's sources are runs, code, docs and write-ups.
- S5 Analysis of competing hypotheses (Wikipedia) — https://en.wikipedia.org/wiki/Analysis_of_competing_hypotheses · version: last edit 2025-12-08 per the subagent's summary of the footer · read: part (whole article body, not the navigation) · says: Heuer's method "discourages the analyst from choosing one 'likely' hypothesis and using evidence to prove its accuracy"; apply evidence "in an attempt to disprove as many theories as possible"; sensitivity: "how the conclusion would be affected if key evidence or arguments were wrong"; name milestones that would signal change; there is "a lack of strong empirical evidence" that it reduces bias. · adopted: disconfirm, give alternatives their best case, and say what would change the answer (practice 6). Not adopted: the full hypothesis-evidence matrix, too heavy for one question.
- S6 Reference class forecasting (Wikipedia) — https://en.wikipedia.org/wiki/Reference_class_forecasting · version: last edit 2026-09-09 · read: whole · says: "identify a reference class of past, similar projects", establish its distribution, compare the case with it; corrects the optimistic "inside view". · adopted: an unmeasured estimate names its reference class and gives a range (practice 7); this addresses estimates like 0002/B's "5,500–8,400 product lines" with no stated basis.
- S7 open_deep_research prompts (LangChain) — https://raw.githubusercontent.com/langchain-ai/open_deep_research/main/src/open_deep_research/prompts.py · version: `main` branch, no commit shown · read: whole file · says: researcher stops when "your last 2 searches returned similar information" or after a fixed number of searches; reflects after each search; the final report numbers each unique URL once and ends with a Sources list; source quality appears only in the scoping prompt ("prefer linking directly to official or primary websites"). · adopted: stop when new sources stop changing the answer (practice 9) and numbered source ids. Not adopted: fixed search-call caps; braid uses the caller's time box instead.
